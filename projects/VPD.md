## Project pitch

Participants will work with an immunity estimation tool, imuGAP, and use the results of that estimation to estimate outbreak distributions for vaccine-preventable-disease.

## Research area(s)

- Data science
- Estimation
- Measles
- Outbreaks

## Data

### Type of data

- Local surveillance data as available; vaccination doses adminstered, coverage surveys, etc

### Source

- Ideally your data! ... but can definitely use US measles data.

### Description and status of data

- No idea how clean *your* data are, but if we use the US data, these have been curated and cleaned

## Software

- [imuGAP](https://accidda.github.io/imuGAP/)

## Potential research question(s)

- What would changing vaccination inputs do to expected outbreak sizes / spatial distribution?
- What do we estimate missing coverage to be?
- Can we detect changes in vaccination patterns?
